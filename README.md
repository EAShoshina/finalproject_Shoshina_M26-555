# finalproject_Shoshina_M26-555

Консольное приложение, имитирующее работу валютного кошелька.

## Возможности
- Управление балансом в разных валютах
- Обмен валют по актуальному курсу
- История операций с форматированным выводом
- Логирование и подтверждение действий
- Кэширование курсов валют

## Установка и запуск
```
bash
uv sync
uv run wallet
```

## Технологии
Python 3.11+, uv, ruff, prettytable, json, shlex
